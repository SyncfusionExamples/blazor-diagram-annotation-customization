# Blazor Diagram Annotation Customization

This repository contains a Syncfusion Blazor Diagram sample that demonstrates advanced annotation customization and document-style editing capabilities. The application allows users to edit annotations at runtime, apply rich text formatting, navigate across pages, and export diagrams.

## Key Features

- Edit diagram annotations dynamically at runtime
- Apply text formatting such as:
  - Font family
  - Font size
  - Font color
  - Bold, Italic, and Underline styles
  - Text alignment
- Create and manage multi-page diagram layouts
- Horizontal and vertical scrolling support
- Export diagrams to supported file formats
- Interactive diagram editing experience

## Prerequisites

- .NET 10.0 SDK
- Visual Studio 2026, Visual Studio Code, or any preferred IDE

## How to Run the Project

**Visual Studio 2026**

1. Clone or download this repository.
2. Open `DiagramFeatures.slnx` in Visual Studio 2026.
3. Restore the NuGet packages.
4. Build the solution.
5. Run the application.
6. Navigate to the home page that hosts the Syncfusion Diagram sample.
7. Explore the available features:
    - Edit annotations at runtime.
    - Apply rich text formatting such as font styles, size, color, and alignment.
    - Navigate through multiple pages.
    - Use scrolling to view large diagram content.
    - Export the diagram to supported formats.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the project directory.

```
dotnet restore
dotnet run
```
